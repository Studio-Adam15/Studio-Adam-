# STUDIO ADAM — Static Website Package

حزمة الموقع الثابتة الرسمية لـ **ستوديو آدم (@studioadam.co)** بصيغة HTML / CSS / JavaScript نقية جاهزة للرفع على أي استضافة بدون الحاجة لأي أدوات بناء.

---

## محتويات المجلد (Contents)

- **`index.html`** — الهيكل الكامل للموقع ثنائي اللغة (العربية RTL والإنجليزية LTR)، متضمناً الصفحة الرئيسية وصفحة معرض الأعمال المستقلة ونوافذ الحجز والمعاينة.
- **`style.css`** — ملف التنسيقات الكامل بالهوية اللونية (#124E52 / #F5F0E6)، الخلفية النقطية، تأثيرات التمرير، وتنسيقات الحاسبة والمعرض.
- **`script.js`** — البرمجة التفاعلية الكاملة (التبديل بين العربية والإنجليزية، التنقل بين الرئيسية وصفحة الأعمال، تصفية المعرض، نافذة Lightbox السينمائية، حاسبة الباقات الفورية بالدينار الأردني، ونموذج الحجز عبر واتساب).
- **`assets/`** — جميع الشعارات، تصاميم السوشيال ميديا الـ 8، وفيديوهات الـ UGC السبعة مرتبطة بمسارات نسبية جاهزة (`./assets/...`).
- **`README.md`** — دليل التشغيل والرفع والتعديل.

---

## طريقة التشغيل محلياً (Local Preview)

> يُنصح بفتح الموقع عبر خادم محلي بسيط لتعمل الفيديوهات والتنقل بسلاسة تامة:

1. **باستخدام VS Code**: ثبّت إضافة **Live Server** ثم اضغط بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.
2. **باستخدام Python**:
   ```bash
   python3 -m http.server 8080
   ```
   ثم افتح المتصفح على `http://localhost:8080`.

---

## الرفع على الاستضافة (Deployment)

ارفع جميع الملفات والمجلدات كما هي (`index.html`، `style.css`، `script.js`، `assets/`) إلى أي استضافة:
- **Netlify / Vercel**: اسحب المجلد مباشرة وأفلته داخل لوحة التحكم.
- **GitHub Pages**: ارفع الملفات إلى المستودع وفعّل GitHub Pages من `Settings > Pages`.
- **cPanel / Hostinger**: ارفع المحتويات داخل مجلد `public_html`.

---

## التعديل السريع (Quick Customization)

- **تعديل الألوان والخطوط**: من أعلى ملف `style.css` داخل `:root`.
- **تعديل الأسعار، رقم الهاتف، رابط واتساب، أو بيانات المعرض**: من أعلى ملف `script.js` داخل `STUDIO_CONFIG` و `PORTFOLIO_ITEMS`.
